# Packages

- `blueprint`: canonical YAML blueprint loading and structural validation.
- `dsl_core`: textual DSL lexer, parser, resolver, and blueprint emitter.
- `generator_nestjs`: deterministic Jinja2 NestJS scaffold generator.
- `llm_providers`: LLM clients, prompt builders, and generation helpers.
- `shared`: shared logging, config, templates, and exceptions.
- `validator`: generated NestJS project validation utilities.
